# 忘れていたでしょう（iOS）

指定場所に近づいたら知らせる忘れ物防止アプリ（Swift / SwiftUI / iOS 18+）。入力はテキスト中心。音声は iOS キーボードのマイクから。

## 実装済み

- **第1**: テキスト入力・「次へ」
- **第2**: 場所／用事抽出、MapKit 検索・候補／地図、予定一覧
- **第3**: 接近時ローカル通知（300/500/1000m）、専用音 `piroriron.caf`、Always 位置の導線
- **第4**: 店舗付近の滞在で自動解除、履歴、ワンタップ再登録
- **自宅**: 設定で自宅を保存し、「帰ったら洗濯」などを自宅へ登録（`stage4-home-1`）
- **呼び名**: 登録した場所を端末内に覚え、次回検索で候補先頭に出す（`stage4-places-1`）
- **地名＋店名の呼び名**: 「金古のセブン」「高崎のイオン」を SavedPlace にそのまま保存。パース／検索／決定で一意マッチ（`stage5-places-2`）
- **保存した場所の一覧**: 設定で SavedPlace だけの一覧。呼び名・住所・地図プレビュー（任意表示）・編集・削除（`stage5-places-3`）
- **保存した場所の新規登録**: 一覧から地図＋呼び名で追加。`SavedPlace` upsert（約50m近傍は更新）（`stage5-places-4`）
- **接近通知の重複抑止**: 圏内にいるあいだ1回まで（`stage4-dedupe-1`）
- **第5（接近読み上げ）**: 接近時に「忘れていたでしょう？○○予定ですよ！」。設定タブ最上付近の専用セクションで大きいボタン（録音開始／停止／再生／差し替え／削除）。録音があればそれを再生してから用事を TTS。無ければ全文 TTS（設定 ON/OFF・声の種類・読み上げテスト）。通知音クリアランス **2.44s**（speech-11 維持）。前面は確実。ホーム退避・画面オフでは進入検知直後に試行。ロック中は端末次第（`stage5-speech-14`）
- **予定編集の地図**: 編集シートで登録座標を Map 表示。タップでピン移動＋逆ジオコードで住所更新（`stage5-editmap-1`）
- **App Icon**: ユーザー提供アイコンを Single Size 1024 で設定（`stage5-icon-1`）
- **場所／用事パース**: SavedPlace 呼び名と自宅・コネクタで内容確認の初期値を分割（`stage5-parse-1`）
- **内容確認の決定＝登録**: 「決定」で場所が決まれば即保存。「予定に登録する」確認は出さない（`stage5-decide-2`）
- **呼び名で決定**: 場所欄が SavedPlace の呼び名（完全一致／明確な部分一致）なら決定で座標確定・即保存（`stage5-decide-2`）
- **地図で場所＋呼び名**: 場所不明時に「地図で場所を登録」→ピン＋呼び名必須で予定保存と SavedPlace upsert（`stage5-mapnick-1`）

ビルド識別: **`build: stage5-speech-14`**

## 未実装／保証外

- ロック画面での読み上げの **100% 保証**（進入直後に発話開始できた場合は聞こえることが多いが、Focus・節電・端末状態で無音になり得る。通知音＋文字がフォールバック）
- クラウド TTS／独自音声ファイル大量同梱／クラウド同期／ログイン

## Mac で開く（取り込み方）

`update-and-open-xcode.command` をダブルクリック（Terminal 不要。初回は右クリック→開く）。`git pull --ff-only` のあと Xcode が開きます。日本語名の `更新してXcodeを開く.command` も同じです。

Signing で Team を選び、実機（iOS 18+）で Run。

```bash
cd WasureteitaDeshou

```

## 実機テスト（読み上げ / speech-5）— ロック含む

1. 設定で `build: stage5-speech-14` を確認（設定タブを開いた直後＝build の直下）
2. 「接近時に読み上げる」がオン（既定）・位置情報は「常に」・通知許可オン
3. 最上付近「「忘れていたでしょう」録音」の大きい「録音開始」→「停止」で保存（マイク許可）→「再生」で確認。「差し替え（再録音）」「削除」できること
4. 「読み上げテスト」で録音→用事 TTS（または録音なしなら全文 TTS）
5. **前面**: 「テスト通知を送る」→ バナー＋通知音のあと読み上げ
6. **ホーム退避（BG）**: 予定の通知圏外→ホームへ→圏内へ進入 → 通知音＋文字のあと、声が出ること（出ない場合あり・下記限界）
7. **画面オフ**: 同様に進入 → 声が出ることがある（保証外）
8. **ロック画面**: ロックしたまま圏内進入 → 通知は来る。声が出れば成功、出なければ通知音＋文字のみで正常。通知をタップして前面に戻ると読み上げること
9. ロックで声が出ないのは iOS／端末の限界として想定内。BG で可能な最大（進入直後の発話試行）まで実装済み

## 実機テスト（接近通知 dedupe）

1. 予定の通知圏内にいる状態で Run／アプリをフォアグラウンドへ戻す
2. 接近通知が **同じ予定について1回だけ** 届くこと
3. 圏外に出てから再度入ると、また1回通知されること

## 実機テスト（呼び名 / places-1）

1. 「金古のセブン」などで予定登録 → 設定「保存した場所」に同じ呼び名で出ること
2. 新規登録で同じ呼び名 → 決定で一意なら即登録／検索なら候補先頭
3. 設定で呼び名の編集・削除ができること
4. 「自宅を使う」で登録しても SavedPlace に自宅が二重保存されないこと

## 実機テスト（地名＋店名 / places-2）

1. 「金古のセブンで牛乳を買う」→ 場所欄が「金古のセブン」になること
2. 検索または地図で座標を決め、登録 → SavedPlace の呼び名が「金古のセブン」（MapKit 店名ではない）こと
3. 次回「金古のセブンで…」または場所欄「金古のセブン」→ 決定で即登録
4. 「高崎のイオン」も同様。地図登録の例も同形式

## 実機テスト（保存した場所一覧 / places-3）

1. 設定 →「保存した場所」で、登録済み SavedPlace だけが一覧になること（自宅は含まれない）
2. 各行に呼び名・住所（なければ座標）が出ること
3. 「地図プレビューを表示」をオフにすると地図が隠れ、オンで戻ること
4. タップで編集画面：地図・住所・緯度経度を確認し、呼び名を保存／削除できること
5. スワイプ削除でも一覧から消えること

## 実機テスト（地図＋呼び名 / mapnick-1）

1. 場所を空のまま用事だけ入力 → 決定 → 「地図で場所を登録」が大きく出ること
2. ピンを置き、呼び名空のままでは「この場所で登録」が押せないこと
3. 呼び名（例：金古のセブン）を入れて確定 → 予定登録＋設定「保存した場所」に出ること
4. 次回「金古のセブン」で決定 → 即登録できること
